# OV Content Pipeline

Agentic content pipeline: raw source material → distilled notes → idea cards → drafts,
with human gates for idea selection and draft approval.

- **State + human surface:** Notion (two databases, filtered views for the gates)
- **Code, prompts, raw corpus:** this repo
- **Runtime:** GitHub Actions (plus a scheduled ingest job on the operator's machine)

Setup and architecture details land here as the pipeline is built out. See SPEC.md to read about the design.
