# Visa launches the Trusted Agent Protocol with Cloudflare

**What happened:** Visa released an open framework, built with Cloudflare, that lets merchants cryptographically recognise legitimate AI agents and receive data about the consumer behind them. Named partners include Adyen, Ant International, Checkout.com, Coinbase, CyberSource, Elavon, Fiserv, Microsoft, Nuvei, Shopify, Stripe and Worldpay. Visa reported that AI-driven traffic to US retail sites grew 4,700% over the prior year.

**Thesis tie:** AI agents crossing organisations. A merchant receiving an agent request has no shared history with the agent; TAP gives it a signed identity claim instead.

**Post angle:** A merchant's bot defences block a legitimate shopping agent because they cannot tell it from a scraper. Visa and Cloudflare's answer is a signature on every request.

**Caution:** The 4,700% figure is Visa's, attribute it. Follow-up (Visa, 18 Dec 2025, https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.21961.html, opened): "hundreds" of controlled agent-initiated transactions completed with 100+ partners, rollout targeted for early 2026. Useful for scale, but these are pilots.
