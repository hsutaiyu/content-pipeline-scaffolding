# Swift ends MT/ISO 20022 coexistence, 22 November 2025

**What happened:** From 22 November 2025, all financial-institution-to-financial-institution payment instructions on Swift are delivered only in ISO 20022 format. MT instructions still sent are either rejected or converted through chargeable contingency processing. The change brings richer, structured data (for example, town and country in dedicated address fields).

**Thesis tie:** A shared message vocabulary is a precondition for reconciliation. It standardises how an event is described between institutions, while each bank still keeps its own ledger and derives its own state.

**Post angle:** Actor: the Swift community. Decision: retire a 50-year-old message format for payments. Consequence: richer data travels with each payment, which supports matching at the other end. This is a format standard, not a shared record, and the distinction is useful.

**Caution:** Don't suggest ISO 20022 "solves" reconciliation, or that it competes with Open Value. Check the press release text by hand before quoting it.
