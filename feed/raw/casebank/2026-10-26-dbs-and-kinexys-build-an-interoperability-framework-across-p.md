# DBS and Kinexys build an interoperability framework across public and permissioned chains

**What happened:** DBS and J.P. Morgan's Kinexys said they are developing a framework so that clients of DBS Token Services and Kinexys Digital Payments can pay each other in tokenised deposits across public and permissioned blockchains. The release frames this as necessary in "an increasingly multi-chain, multi-issuer world".

**Thesis tie:** Reconciliation across boundaries. Two of the largest bank ledger operators each run their own record, so they need a framework to agree across them, much as banks already do across separate core systems.

**Post angle:** Two banks that each built their own ledger now need a third piece of work so that their ledgers can talk to each other. Each shared record created another boundary to bridge.

**Caution:** JPMD also runs on Base, a public chain. Avoid crypto and price framing and stay with the interbank workflow.
